题面速览

  • 背景知识：从零设计 Tiled GEMM 的五个映射；BM、BN、BK 各管什么 的图 2（128 B swizzle 和 ldmatrix 的 bank 组）；端到端例子 第 4 节（同样的映射在 64×32 tile 上的坐标表）。上机准备见 F1。
  • 设计已经给出：gpu/tiled_gemm_config.hpp 里的 cfg::Config<128,128,64,1,2,4> ——SMEM layout、G2SCopy、TiledMma、S2RAtom 四个类型。kernel 和 oracle 都 include 它，所以 oracle 打印的坐标就是 kernel 真正用的。
  • 你要写：
  1. mine/f2_tensorcore_gemm.cu 的四个 DRILL_TODO ：① local_tile ；② G2SCopy 的 partition_S / partition_D ；③ TiledMma 的 partition_A / partition_B （直接对 SMEM）、partition_C 、make_fragment_C ；④ K 循环（cp.async → fence → wait → sync → gemm → sync）和写回。
  2. mine/f2_tensorcore_gemm.py ：copy_starts / copy_coords 、smem_offset / bank_group 、mma_c_coords 、smem_bytes 、mma_per_ktile 。
  • 关键规则：
  1. 拷贝：线程排成 (32,8):(8,1)，每线程一次 8 个 BF16 = 16 B；(128,64) 要 4 轮，起点 (t // 8 + 32i, 8(t % 8)) 。
  2. SMEM：smem_offset(r, k) = 512·(r // 8) + 64·j + 8·((r % 8) ⊕ j) + k % 8 ，j = k // 8。
  3. MMA：warp w 的 (wm, wn) = (w % 2, w // 2)；lane 的 4 个累加器在行 lane // 4 （+8）、列 2(lane % 4) （+1）；自然覆盖 32×32，在 128×128 上沿 M、N 各重复 4 次。

测试检查：8 个线程的 copy partition、9 个线程的 MMA partition、整个 (128,64) 的 SMEM 偏移表都和真实 CuTe 一致 · 每 8 行的每个 16 B 块落在 8 个不同的 bank 组 · 覆盖不重不漏 · 计数 · .cu 类型检查 · GPU 上 1024³ 和 4096³ 对拍。

直觉与类比

类比 · 换上冲压机，但还是“一箱一箱”地干

F1 的小组用普通机床；F2 换成了 Tensor Core 这台冲压机：8 个班组（warp）各管一片 64×32 的零件，每次冲压（mma.sync）一个 warp 一起出 16×8×16 的结果。料从仓库搬上工作台用了自动叉车的前身 cp.async（每个工人一次搬 16 B，不经过自己的工具台），工作台上的料按 swizzle 错开摆，取料时 8 个人不会挤在同一个抽屉前。但现在仍然是“搬完一箱 → 全体等 → 冲压 → 全体等 → 再搬下一箱”，冲压机一半时间在等料——F3 用流水线解决。

1. ① local_tile

和 F1 完全一样，只是 tiler 变成 (128,128,64)：gA (128,64,K/64)、gB (128,64,K/64)、gC (128,128)。

2. ② G2SCopy：谁搬哪 16 B

auto thr = g2s.get_slice(threadIdx.x); tAgA = thr.partition_S(gA); tAsA = thr.partition_D(sA);。tAgA 的形状 ((8,1),4,1,k)：第一维是“一条 cp.async 的 8 个值”，第二维是 4 轮。partition_S 和 partition_D 用同一套分工，所以 copy(g2s, tAgA(_,_,_,kt), tAsA) 就是每个线程发 4 条 16 B 的 cp.async，源和目的一一对应。

3. ③ TiledMma：谁持有哪些操作数和累加器

thr_mma.partition_A(sA) 给出这个线程在 mma 里要用的 A 元素（在 SMEM 里的位置），partition_C(gC) 给出它负责的 64 个输出在全局 C 里的位置，make_fragment_C(tCgC) 建同形状的 FP32 寄存器数组。形状 ((2,2),4,4)：一个 atom 4 个值 × M 方向 4 次 × N 方向 4 次。

4. ④ K 循环

copy(g2s, …) 两次 → cp_async_fence()（把刚发的 cp.async 打成一组）→ cp_async_wait<0>()（等本线程的所有组落地）→ __syncthreads()（等所有线程）→ gemm(mma, tCsA, tCsB, tCrC)（4 个 k16 步）→ __syncthreads()。

5. 写回

copy(tCrC, tCgC)：每个线程写 64 个 float，每对相邻的两个（列 +0/+1）在内存里连续。

L2思路拆解拆解与常见坑（中度剧透）

所有 partition 都是“先 get_slice(threadIdx.x) ，再 partition_* ”。G2SCopy 对 gA 用 partition_S 、对 sA 用 partition_D ；TiledMma 对 sA 用 partition_A 、对 sB 用 partition_B 、对 gC 用 partition_C 。SMEM 只有一级，所以 make_tensor(..., SmemLayoutA{})(_, _, 0) 取出那一级。主机部分：mma_c_coords 的四层循环顺序是 N 重复（最外）→ M 重复 → 行 +0/+8 → 列 +0/+1（最内）。

L3关键问题的答案几乎是答案（重度剧透）

为什么 cp_async_wait<0>() 之后还要 __syncthreads()？

cp_async_wait 只等本线程发的 cp.async。mma 要用的 A 元素是别的线程搬的，所以还要 __syncthreads() 等所有线程都 wait 完。反过来，只有 __syncthreads() 而没有 wait 也不行：cp.async 是异步的，线程到达 barrier 时它发的拷贝可能还在路上。

GPU 部分在 `f2_tensorcore_gemm.cu`：五个映射（gpu/tiled_gemm_config.hpp 里的 Config<128,128,64,1,2,4>）变成真实的

和真实 CuTe 的输出（oracle/f2_tensorcore_gemm.cpp → tests/golden）对拍。

① Copy TV（G2SCopy）：线程排成 (32,8):(8,1)，每线程每次 (1,8) 个 BF16 = 16 B
- 线程 t 在线程布局里是 (t // 8, t % 8)；一轮覆盖 32 行 × 64 列，(128,64) 的 tile 要 4 轮（沿 M）。
- copy_starts(t)：4 条 cp.async 的起点 (t // 8 + 32·i, 8·(t % 8))，i = 0..3；每条向 K 方向连续 8 个元素。
- copy_coords(t)：展开成 32 个 (m, k)，顺序是“先 8 个值，再下一轮”（partition_S 的 (CPY, CPY_M, CPY_K) 顺序）。

② SMEM（SmemLayoutA = tile_to_shape(Swizzle<3,3,3> ∘ (8,(8,8)):(8,(1,64)), (128,64))）
- 一个 atom 是 8 行 × 64 列 = 512 个元素（1 KB）；atom 沿 M 堆叠：第 r 行在第 r // 8 个 atom 里。
- atom 内：块号 j = k // 8（16 B 一块），行 r' = r % 8，偏移 = 64·j + 8·(r' ⊕ j) + k % 8。
- smem_offset(r, k) = 512·(r // 8) + 64·j + 8·((r % 8) ^ j) + k % 8（元素偏移，乘 2 是字节）。
- bank_group(r, k) = (smem_offset(r, k)·2 // 16) mod 8：这个元素所在的 16 B bank 组。
  ldmatrix 读“8 行的同一块”时，这 8 个 bank 组应当两两不同。

③ MMA（TiledMma：2×4 个 warp 的 SM80_16x8x16，Tile<32,64,16>）在 (128,128) 的 C tile 上
- 线程 t：warp w = t // 32，lane = t % 32，wm = w % 2，wn = w // 2（warp 排列 (2,4) 列主序）。
- 一个 atom（16×8）里 lane 的 4 个累加器：行 lane // 4 和 lane // 4 + 8，列 2·(lane % 4) 和 +1。
- 一个 TiledMMA 的“自然覆盖”是 32×32（2 个 warp × 16 行，4 个 warp × 8 列）；在 128×128 上沿 M 重复 4 次（步长 32），
  沿 N 重复 4 次（步长 32）。
- mma_c_coords(t)：64 个 (m, n)，顺序 = partition_C 的 ((2,2), 4, 4)：
  先列 +0/+1，再行 +0/+8，再 M 重复，最后 N 重复。

计数
- smem_bytes(BM, BN, BK, stages) = stages·(BM + BN)·BK·2
- mma_per_ktile(BM, BN, BK) = (BM/16)·(BN/8)·(BK/16)：一个 CTA 每个 k-tile 发多少条 mma.sync

API
    BM, BN, BK, THREADS, WARP_M, WARP_N                     given
    copy_starts(t) -> [(m, k), ...]                         长度 4
    copy_coords(t) -> [(m, k), ...]                         长度 32
    smem_offset(r, k) -> int                                0 <= r < 128, 0 <= k < 64，否则 ValueError
    bank_group(r, k) -> int
    mma_c_coords(t) -> [(m, n), ...]                        长度 64
    smem_bytes(BM, BN, BK, stages) -> int
    mma_per_ktile(BM, BN, BK) -> int
"""
from __future__ import annotations

BM, BN, BK, THREADS, WARP_M, WARP_N = 128, 128, 64, 256, 2, 4


def _check_t(t: int) -> None:
    if not 0 <= t < THREADS:
        raise ValueError(f"thread {t} out of range [0, {THREADS})")


def copy_starts(t: int) -> list:
    _check_t(t)
    rows_per_pass = THREADS // 8
    return [(t // 8 + rows_per_pass * i, 8 * (t % 8)) for i in range(BM // rows_per_pass)]


def copy_coords(t: int) -> list:
    return [(m, k + v) for (m, k) in copy_starts(t) for v in range(8)]


def smem_offset(r: int, k: int) -> int:
    if not (0 <= r < BM and 0 <= k < BK):
        raise ValueError(f"({r}, {k}) outside the ({BM}, {BK}) tile")
    j = k // 8
    return 512 * (r // 8) + 64 * j + 8 * ((r % 8) ^ j) + k % 8


def bank_group(r: int, k: int) -> int:
    return (smem_offset(r, k) * 2 // 16) % 8


def mma_c_coords(t: int) -> list:
    _check_t(t)
    w, lane = divmod(t, 32)
    wm, wn = w % WARP_M, w // WARP_M
    row0, col0 = 16 * wm + lane // 4, 8 * wn + 2 * (lane % 4)
    cover_m, cover_n = 16 * WARP_M, 8 * WARP_N
    out = []
    for nr in range(BN // cover_n):
        for mr in range(BM // cover_m):
            for dr in (0, 8):
                for dc in (0, 1):
                    out.append((row0 + dr + cover_m * mr, col0 + dc + cover_n * nr))
    return out


def smem_bytes(BM: int, BN: int, BK: int, stages: int) -> int:
    return stages * (BM + BN) * BK * 2


def mma_per_ktile(BM: int, BN: int, BK: int) -> int:
    return (BM // 16) * (BN // 8) * (BK // 16)

// F2 · 第一个 Tensor Core GEMM：TiledCopy（cp.async 16 B）+ swizzle 过的 SMEM + TiledMMA（mma.sync）— reference solution.
//
// Track A 的五个映射在这里第一次变成真实的 GPU 代码：
//   ① CTA tile   local_tile(mA, (BM,BN,BK), (bm,bn,_))
//   ② Copy TV    G2SCopy.partition_S / partition_D：每线程一次 16 B 的 cp.async
//   ③ SMEM       Swizzle<3,3,3> ∘ (8,(8,8)):(8,(1,64))，一行 128 B
//   ④ MMA TV     TiledMma.partition_A / partition_B：从 SMEM 直接读（cute::gemm 内部用普通 LDS 搬进寄存器）
//   ⑤ 累加器     TiledMma.partition_C + make_fragment_C，K 全部走完才写回
// 只有一级 SMEM：每个 k-tile 都是“搬 → 等 → 算 → 等”，访存延迟完全露在外面。F3 再加流水线和 ldmatrix。
//
// 配置：128×128×64，Stages = 1（32 KB SMEM），256 线程 = 2×4 个 warp，每线程 64 个 FP32 累加器。
// 前提：M % 128 == 0、N % 128 == 0、K % 64 == 0。
//
// 运行：python3 tools/cu_drill.py run solutions/f2_tensorcore_gemm.cu 4096 4096 4096
#include <cute/tensor.hpp>

#include "common.cuh"
#include "tiled_gemm_config.hpp"

using namespace cute;

namespace f2 {

using Cfg = cfg::Config<128, 128, 64, /*Stages=*/1, /*WarpM=*/2, /*WarpN=*/4>;
using TA = Cfg::TA;
using TB = Cfg::TB;
using TC = Cfg::TC;

__global__ __launch_bounds__(Cfg::Threads) void gemm_kernel(int M, int N, int K, TA const* A, TB const* B, TC* C) {
  // ① 全局张量 → 这个 CTA 的 tile
  Tensor mA = make_tensor(make_gmem_ptr(A), make_shape(M, K), make_stride(K, Int<1>{}));   // (M,K) K 连续
  Tensor mB = make_tensor(make_gmem_ptr(B), make_shape(N, K), make_stride(K, Int<1>{}));   // (N,K) K 连续
  Tensor mC = make_tensor(make_gmem_ptr(C), make_shape(M, N), make_stride(N, Int<1>{}));   // (M,N) N 连续
  // [TODO ①] local_tile：gA (BM,BK,k)、gB (BN,BK,k)、gC (BM,BN)
  auto cta_tiler = make_shape(Int<Cfg::BM>{}, Int<Cfg::BN>{}, Int<Cfg::BK>{});
  auto cta_coord = make_coord(blockIdx.x, blockIdx.y, _);
  Tensor gA = local_tile(mA, cta_tiler, cta_coord, Step<_1, X, _1>{});   // (BM,BK,k)
  Tensor gB = local_tile(mB, cta_tiler, cta_coord, Step<X, _1, _1>{});   // (BN,BK,k)
  Tensor gC = local_tile(mC, cta_tiler, cta_coord, Step<_1, _1, X>{});   // (BM,BN)
  // [/TODO]

  // ③ SMEM（只有一级，32 KB，静态分配就够）
  __shared__ __align__(128) TA smemA[cosize_v<Cfg::SmemLayoutA>];
  __shared__ __align__(128) TB smemB[cosize_v<Cfg::SmemLayoutB>];
  Tensor sA = make_tensor(make_smem_ptr(smemA), Cfg::SmemLayoutA{})(_, _, 0);   // (BM,BK)
  Tensor sB = make_tensor(make_smem_ptr(smemB), Cfg::SmemLayoutB{})(_, _, 0);   // (BN,BK)

  // ② GMEM → SMEM 的线程分工
  // [TODO ②] G2SCopy 的 get_slice / partition_S / partition_D：tAgA、tAsA、tBgB、tBsB
  typename Cfg::G2SCopy g2s;
  auto thr_g2s = g2s.get_slice(threadIdx.x);
  Tensor tAgA = thr_g2s.partition_S(gA);   // (CPY,CPY_M,CPY_K,k)
  Tensor tAsA = thr_g2s.partition_D(sA);   // (CPY,CPY_M,CPY_K)
  Tensor tBgB = thr_g2s.partition_S(gB);
  Tensor tBsB = thr_g2s.partition_D(sB);
  // [/TODO]

  // ④ ⑤ MMA 分工：A、B 从 SMEM 分，C 在寄存器里
  // [TODO ③] TiledMma 的 partition_A / partition_B（直接对 SMEM）、partition_C、make_fragment_C，累加器清零
  typename Cfg::TiledMma mma;
  auto thr_mma = mma.get_slice(threadIdx.x);
  Tensor tCsA = thr_mma.partition_A(sA);        // (MMA,MMA_M,MMA_K)  指向 SMEM
  Tensor tCsB = thr_mma.partition_B(sB);        // (MMA,MMA_N,MMA_K)
  Tensor tCgC = thr_mma.partition_C(gC);        // (MMA,MMA_M,MMA_N)  指向全局 C
  Tensor tCrC = thr_mma.make_fragment_C(tCgC);  // 同样形状的寄存器累加器
  clear(tCrC);
  // [/TODO]

  // [TODO ④] K 循环：cp.async → fence → wait<0> → __syncthreads → gemm(mma, …) → __syncthreads；最后写回
  int k_tiles = size<3>(tAgA);
  for (int kt = 0; kt < k_tiles; ++kt) {
    copy(g2s, tAgA(_, _, _, kt), tAsA);   // 发 cp.async：每线程 4 条（A）+ 4 条（B），每条 16 B
    copy(g2s, tBgB(_, _, _, kt), tBsB);
    cp_async_fence();
    cp_async_wait<0>();                   // 等本线程发的 cp.async 落地
    __syncthreads();                      // 等所有线程的都落地，SMEM 才完整

    gemm(mma, tCsA, tCsB, tCrC);          // 4 个 k16 步 × 每 warp 16 条 mma.sync

    __syncthreads();                      // 大家都算完，下一轮才能覆盖 SMEM
  }

  copy(tCrC, tCgC);                       // epilogue：FP32 累加器直接写回
  // [/TODO]
}

inline void launch(int M, int N, int K, TA const* A, TB const* B, TC* C, cudaStream_t stream = 0) {
  dim3 grid(M / Cfg::BM, N / Cfg::BN);
  gemm_kernel<<<grid, Cfg::Threads, 0, stream>>>(M, N, K, A, B, C);
}

}  // namespace f2

int main(int argc, char** argv) {
  auto a = drill::parse(argc, argv);
  if (a.M % 128 || a.N % 128 || a.K % 64) {
    std::printf("{\"ok\": false, \"error\": \"F2 needs M,N %% 128 == 0 and K %% 64 == 0\"}\n");
    return 1;
  }
  std::vector<__nv_bfloat16> hA(size_t(a.M) * a.K), hB(size_t(a.N) * a.K);
  drill::fill_bf16(hA, 1);
  drill::fill_bf16(hB, 2);
  auto* dA = drill::to_device(hA);
  auto* dB = drill::to_device(hB);
  float* dC = nullptr;
  CUDA_CHECK(cudaMalloc(&dC, size_t(a.M) * a.N * sizeof(float)));

  auto go = [&] { f2::launch(a.M, a.N, a.K, reinterpret_cast<f2::TA const*>(dA), reinterpret_cast<f2::TB const*>(dB), dC); };
  go();
  CUDA_CHECK(cudaDeviceSynchronize());
  std::vector<float> got(size_t(a.M) * a.N);
  CUDA_CHECK(cudaMemcpy(got.data(), dC, got.size() * sizeof(float), cudaMemcpyDeviceToHost));
  double err = drill::max_rel_err(got, drill::reference(a.M, a.N, a.K, dA, dB));
  float ms = drill::time_ms(go, a.iters);
  drill::report("f2_tensorcore_128x128x64_s1", a, err, ms);
  return 0;
}
